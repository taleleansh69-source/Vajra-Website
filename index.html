Power system notes

Keep battery power and logic power correctly separated.

Battery: 3S LiPo → PDB → ESC power inputs
MPU6050: use 3.3 V, not 5 V
Ground: ESC signal ground and ESP32-C3 GND must be common
Never connect the 3S battery directly to ESP32-C3 GPIO pins or the MPU6050.

Bench-test commands

Commands match the bench-test firmware: TEST, STOP, and MIN.

Remove every propeller and secure the frame before sending a motor test command. TEST sends the firmware's low-throttle pulse to all four ESCs for two seconds.

Commands are enabled only after a real BLE connection. Demo mode cannot command motors.
